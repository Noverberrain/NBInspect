# 浏览器演示

在项目根目录运行：

```powershell
./scripts/build_web.ps1
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

然后打开 http://127.0.0.1:8765/ 。页面使用本地构建的 MoonBit JS 模块；每次修改 MoonBit 核心后重新运行构建脚本。浏览器页面不能直接通过 `file://` 打开，因为模块 Worker 需要本地 HTTP 服务。

选择原始 `.ipynb` 后可运行发布检查；再选择修改后的文件可比较差异。显示范围支持全部、仅代码、代码与文字；结果可下载 JSON 或独立 HTML 报告。“试用示例”无需准备文件。单文件上限 10 MiB，分析在浏览器 Worker 内完成，文件不会上传，也不会执行 Notebook 中的 Python 代码。

## 发布风险审阅

选择修改前、修改后两个文件，点击“审阅发布风险”。报告区汇总新增、已有、已消除和待确认四种状态，可用“风险状态”筛选；显示范围选项只用于差异比较。点击“试用风险示例”可直接体验四种风险状态。

待确认表示无法可靠建立单元格对应关系，需要人工复核。浏览器使用默认 error 阻断级别，仅新增达到该级别的风险影响报告状态；显示“未新增阻断级别风险”仍可能有 warning、已有风险或待确认项。

风险卡片显示修改前后的规则、严重程度、位置、内容及匹配依据。筛选在 Worker 中复用完整审阅结果，不重复分析 Notebook；JSON 与 HTML 下载始终包含全部风险和匹配证据，便于离线复核。
