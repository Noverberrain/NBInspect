# 浏览器演示

在项目根目录运行：

```powershell
./scripts/build_web.ps1
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

然后打开 http://127.0.0.1:8765/ 。页面使用本地构建的 MoonBit JS 模块；每次修改 MoonBit 核心后重新运行构建脚本。浏览器页面不能直接通过 `file://` 打开，因为模块 Worker 需要本地 HTTP 服务。

选择原始 `.ipynb` 后可运行发布检查；再选择修改后的文件可比较差异。显示范围支持全部、仅代码、代码与文字；结果可下载 JSON 或独立 HTML 报告。“试用示例”无需准备文件。单文件上限 10 MiB，分析在浏览器 Worker 内完成，文件不会上传，也不会执行 Notebook 中的 Python 代码。

## 发布风险审阅

选择修改前、修改后两个文件，点击“审阅发布风险”。报告区汇总新增、已有、已消除和待确认四种状态，可用“风险状态”筛选；显示范围选项只用于差异比较。点击“试用风险示例”可直接体验四种风险状态。

待确认表示无法可靠建立单元格对应关系，需要人工复核。未导入配置时使用默认 error 阻断级别；导入后使用配置指定的等级，仅新增达到该级别的风险影响报告状态；显示“未新增阻断级别风险”仍可能有 warning、已有风险或待确认项。

风险卡片显示修改前后的规则、严重程度、位置、内容及匹配依据。筛选在 Worker 中复用完整审阅结果，不重复分析 Notebook；JSON 与 HTML 下载始终包含全部风险和匹配证据，便于离线复核。


## Notebook 体积分析

选择原始 `.ipynb`，点击“分析原始文件体积”；无需选择修改后文件。点击“试用体积示例”可直接体验包含流输出、多个 MIME 表示和附件的 Notebook。

- 页面汇总紧凑 JSON 总字节数、输出与附件字节数、单元格数量；报告按体积降序展示全部单元格、MIME 汇总及具体资源 JSON Pointer 路径。索引从 0 开始。
- 统计由 MoonBit 在 Worker 中完成，采用紧凑 JSON 序列化后的 UTF-8 字节数，包含字符串引号和转义，不计原文件缩进，也不解码 base64 或图片。不执行 Notebook，不上传文件。
- JSON 与 HTML 下载为 `nbinspect-profile.json` 和 `nbinspect-profile.html`，保存完整统计；报告包含 ID、MIME 和资源名称，但不复制源代码或资源正文。HTML 可离线打开，不渲染存储的 HTML、SVG 或图片内容。
- 单个文件上限 10 MiB、10,000 个单元格、10,000 个资源值，支持 nbformat 4.0–4.5；超限、损坏或无法读取时清空旧报告并显示失败，避免下载上一份结果。
- 体积分析只读取原始文件，不受差异显示范围、风险筛选或发布规则影响；规则无效或正在校验时也能运行。更改／恢复规则、重新选择文件或切换操作会清除已有报告及下载链接。

如需分析修改后版本，将它选择为“原始文件”。单文件体积报告只分析当前选择的一个版本。

## 版本体积比较

选择原始及修改后两个 `.ipynb`，点击“比较体积变化”；“试用体积变化示例”展示单元格移动、输出增长和附件增大，不代表 Notebook 执行结果。真实文件按钮始终读取当前选中的两份文件，不会复用示例。

- 页面摘要显示总体、正文、输出、附件和其他字节增减，以及匹配、未匹配和旧单元格歧义数量。正数表示增长，负数表示缩减，全部为 **修改后 − 原始**。
- 报告复用 MoonBit `profile-diff` 核心，按增减绝对值排列全部单元格，保留零变化项、前后位置、分类字节、匹配依据及移动标记；另有 MIME 汇总与外围结构增减。未匹配贡献不代表确认新增／删除，歧义需人工复核。同体积不代表同内容。
- 下载文件为 `nbinspect-profile-diff.json`／`.html`，保存完整结果；HTML 可离线打开，不复制源代码或资源正文，不渲染存储媒体。统计仍为紧凑 JSON UTF-8 字节数，不是原文件大小、解码媒体大小或精确清理收益。
- 每份文件上限 10 MiB、10,000 个单元格、10,000 项资源；复用核心的匹配候选预算和文本限制，超限或任一输入损坏会清空旧结果并显示错误，不输出截断成功报告。
- 发布规则无效或校验中仍可比较体积。差异显示范围和风险筛选不影响体积统计；重新选文件、切换操作、修改／恢复规则或离开页面会取消旧分析并清理下载链接。

## 浏览器增长预算检查

1. 展开“体积增长预算”，导入 `configs/growth-budget.json` 或自己的独立预算 JSON（最多 1 MiB）。MoonBit 校验后显示有效配置；没有有效预算时“检查增长预算”停用，不会自动采用默认额度。
2. 选择原始和修改后两份 Notebook，点击“检查增长预算”。页面显示通过／未通过及总体、输出、附件的超额字节；HTML 报告提供逐项前后大小、增长、额度、超额及完整比较证据。
3. 通过和超额报告均可下载为 `nbinspect-budget.json`／`.html`，下载不受差异范围或风险筛选影响。“通过”仅表示已配置的体积额度未超出，发布风险需另行审阅。

额度按修改后减原始的紧凑 JSON UTF-8 字节数判断，大于额度才超限；恰好达到、零变化、缩减通过。`0` 表示不允许正增长；未配置的类别不检查。配置至少包含一项，支持 `max_notebook_growth_bytes`、`max_output_growth_bytes`、`max_attachment_growth_bytes`，值为 0–2,147,483,647 的整数。未知字段、负数、小数、字符串和发布规则配置均会拒绝，错误指出字段路径。

“试用预算超额示例”无需文件或配置，使用明确标注的独立零增长额度，展示输出和附件增长造成的阻断。它不会替换已导入预算；点击真实文件检查按钮仍使用当前选择的文件和有效配置。演示数据为手工存储样本，不代表执行结果。

预算与发布规则独立：发布规则无效或校验中仍可检查预算；预算无效不影响其他分析操作。更换或清除预算立即取消旧分析、撤销下载链接；读取／校验期间真实预算检查停用，晚到的回调不会覆盖新配置。清除后需重新导入，刷新后也不保留配置。

每份 Notebook 上限 10 MiB，并沿用核心的单元格、资源、匹配候选和格式限制。任何错误清空旧结果，不生成截断成功报告。全部分析在本地 Worker 中完成，不上传文件或执行代码；保存的 HTML 可离线打开。

## 导入发布规则

1. 展开工作台的“发布规则”，选择 UTF-8 JSON 文件（最多 1 MiB）。可直接使用仓库中的 `configs/teaching.json`、`configs/research.json` 或 `configs/sharing.json`。
2. 校验成功后显示文件名、阻断等级和完整有效配置，缺省字段沿用默认值。检查与风险审阅使用这份策略；纯差异比较和体积分析不读取策略。
3. 点击“检查原始文件”或“审阅发布风险”重新分析。风险筛选只改变显示，下载的完整 JSON 与 HTML 都记录有效策略。
4. 点击“恢复默认规则”清空配置；修改或恢复配置时会立即清除旧报告和下载链接，避免误用上一份策略的结果。

配置错误会给出字段路径；格式规则 FMT001／FMT002 仍必须启用并保持 error。无效、超限或无法读取的配置不会静默回退，检查和风险审阅按钮会停用；差异比较和体积分析仍可使用。重新选择有效配置或恢复默认即可继续。分析和配置校验均在本地 Worker 中完成，页面刷新后恢复默认规则。
